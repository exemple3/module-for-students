# Карьерный навигатор (Модуль абитуриента)

Учебный проект для помощи абитуриентам в выборе IT-профессии и подходящего вуза.

Проект показывает, какие навыки нужны работодателям, сколько платят на вакансиях, и в каких вузах этому учат. Также есть тест для подбора профессии.

## Как пользоваться сайтом

1. Вкладка "Реестр профессий":
   Здесь можно искать профессии по названию или навыкам (например, python или sql). Если нажать кнопку "Показать вузы и вакансии", откроются программы обучения и реальные вакансии с зарплатами. Если войти в аккаунт, профессию можно сохранить в избранное.

2. Вкладка "Программы вузов":
   Здесь показан список университетов, направления подготовки, проходные баллы и экзамены ЕГЭ. Нажав на квалификацию внутри программы, можно сразу перейти к подходящим вакансиям. Программы тоже можно сохранять в избранное.

3. Вкладка "Диагностика":
   Это тест из 8 простых вопросов. В каждом вопросе можно выбрать один или несколько вариантов ответа. Внизу можно ввести свои баллы ЕГЭ и нажать "Рассчитать результаты". Система посчитает проценты совпадения по профессиям, покажет главную рекомендацию и отметит, куда хватает баллов.

4. Вкладка "Личный кабинет":
   Здесь можно зарегистрироваться или войти. Внутри отображаются два списка: сохраненные программы вузов и сохраненные профессии.

## Стек технологий

- Frontend: HTML, CSS, Vue.js (Options API)
- Backend: Node.js, Express.js
- База данных: MySQL
- Авторизация и безопасность: bcryptjs, jsonwebtoken, параметризованные запросы к базе

## Инструкция по запуску

1. Загрузка базы данных:
- Открыть MySQL Workbench
- Нажать File -> Open SQL Script и выбрать файл database.sql из папки проекта
- Нажать на значок молнии (выполнить), чтобы создать базу career_navigator

2. Настройка:
- Открыть файл db.js в проекте
- Указать свой пароль от MySQL в поле password

3. Установка и запуск:
- Открыть терминал в папке проекта
- Написать команду: npm install
- Запустить сервер командой: npm run dev (или node index.js)

4. Просмотр сайта:
- Открыть браузер и перейти по адресу: http://localhost:5000
